# Session 6: Unix File System and Command Line

Working directly in the shell. Students learn to navigate the file system,
combine small tools with pipes and redirection, and reason about relative
versus absolute paths.

## Objectives

- Navigate files and directories in a Unix environment.
- Use common command-line tools.
- Understand relative and absolute paths.

## Topics

- `pwd`, `ls`, `cd`, `mkdir`, `cp`, `mv`, `rm`.
- Redirection and pipes.
- File organization.
- Basic permissions.

## In-class activity

A guided terminal workflow exercise.

## Homework

Organize files, run scripts from the shell, and demonstrate correct
command-line usage.
