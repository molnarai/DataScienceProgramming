# Session 3: Loops and Core Data Structures

Repetition plus the containers that make it useful. This session establishes
the counting and accumulation patterns that reappear throughout the course.

## Objectives

- Use `for` and `while` loops appropriately.
- Work with lists, tuples, sets, and dictionaries.
- Recognize patterns such as counting and accumulation.

## Topics

- Iteration.
- Indexing and slicing.
- Membership tests.
- Dictionary-based counting.

## In-class activity

Compute category counts from a small dataset.

## Homework

Use loops and dictionaries to summarize structured input data.
