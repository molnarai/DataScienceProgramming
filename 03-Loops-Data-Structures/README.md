# Session 3: Loops and Core Data Structures

One week of transactions at a campus coffee cart, and the Python needed to ask
questions of it: which items sell most, when sales peak, and which customer
groups buy what. Small enough to check by eye, structured enough to practice
every container and loop pattern the rest of the term depends on.

## Objectives

- Choose between a list, tuple, set, and dictionary, and justify the choice.
- Write `for` loops over collections and `while` loops over conditions.
- Apply the four core loop patterns: counting, accumulating, filtering, and
  finding a maximum.
- Build a counts dictionary by hand, then with `.get()`, then with `Counter`.
- Explain what a later one-line `groupby()` or `value_counts()` is doing.

## Topics

- Lists: indexing from 0, slicing, mutation, and building new lists.
- Tuples: fixed records and unpacking.
- Sets: uniqueness and membership testing.
- Dictionaries: key lookup, `.get()`, and `.items()`.
- `for` versus `while`; `range()` and `enumerate()`.
- Counting and accumulating into a dictionary; `collections.Counter`.
- Data-quality checks with membership tests.
