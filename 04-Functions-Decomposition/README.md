# Session 4: Functions and Decomposition

Moving from scripts of straight-line code to reusable pieces. Students write
functions with clear inputs and outputs, and break a larger task into steps
that can be tested independently.

## Objectives

- Write reusable functions.
- Use parameters and return values correctly.
- Break a larger task into smaller steps.

## Topics

- Function definitions.
- Scope.
- Docstrings.
- Simple testing.

## In-class activity

Refactor repetitive code into functions.

## Homework

Implement several small functions and pass an autograder test suite.
