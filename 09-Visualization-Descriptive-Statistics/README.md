# Session 9: Visualization and Descriptive Statistics

Seeing and summarizing data. Students pair the standard chart types with the
numeric summaries that describe the same distribution, and practice stating
what a figure actually shows.

## Objectives

- Create informative plots.
- Compute and interpret basic summary statistics.
- Communicate findings clearly.

## Topics

- Histograms, bar charts, scatter plots, line plots.
- Mean, median, variance, standard deviation.
- Outliers and distribution shape.

## In-class activity

Compare two variables visually and numerically.

## Homework

Produce plots and descriptive statistics and answer short interpretation
prompts.
