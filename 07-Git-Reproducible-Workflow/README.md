# Session 7: Git and Reproducible Workflow

Version control as a working habit rather than a chore. Students track their
own changes, read a commit history, and use Git as the submission mechanism
for the rest of the term.

## Objectives

- Understand why version control matters.
- Track changes with Git.
- Use Git as part of assignment submission.

## Topics

- Repository basics.
- `git status`, `git add`, `git commit`, `git log`.
- Remote repositories.
- Meaningful commit messages.

## In-class activity

Create a repository, make edits, and inspect commit history.

## Homework

Submit a small assignment through the Git-based workflow with multiple
commits.
