# Session 2: Types, Strings, and Conditionals

Python's core scalar types and the first control flow. Students learn what a
value's type implies, how to convert between types deliberately, and how to
branch on a condition.

## Objectives

- Recognize common Python data types.
- Convert between types when appropriate.
- Write simple branching logic.

## Topics

- Integers, floats, strings, booleans.
- String operations and common methods.
- Comparisons.
- `if`, `elif`, and `else`.

## In-class activity

Classify simple values and transform short text inputs.

## Homework

A small text-processing task using strings and conditionals.
