# Session 14: Integration and Review

Putting the term together. Students revisit core Python ideas, sharpen
debugging and testing habits, and organize a project so someone else could
reproduce it.

## Objectives

- Combine programming, analysis, and workflow skills.
- Strengthen debugging and interpretation habits.
- Demonstrate readiness for follow-on coursework.

## Topics

- Review of core Python ideas.
- Debugging and testing.
- Reproducible file organization.
- Connecting programming skills to later data science work.

## In-class activity

An integrative coding and interpretation exercise.

## Homework

A cumulative assignment combining functions, files, analysis, and one
algorithmic component.
